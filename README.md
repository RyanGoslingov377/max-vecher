# max-vecher

Мини-приложение и бот для МАКС: подбираем вечер по настроению и зовём друзей карточкой «Иду / Может / Не могу» в групповом чате. Конкурс МАКС × Минобрнауки, трек «Досуг и развлечения».

Подробно про продукт, подбор и план — в документе команды: https://claude.ai/code/artifact/a21cfe51-a584-4ae4-8d55-b5dbe6b33651 (попроси доступ у капитана).

## Что сейчас работает

- Бот `@t420_hakaton_max_bot` отвечает на `/help` и `/вечер`.
- `/вечер` присылает тестовую карточку с кнопками, счётчик обновляется при нажатии.
- Голоса пока хранятся в памяти и пропадают при перезапуске.

## Первый запуск (один раз)

Нужны Git и Python 3.12. В терминале, в папке проекта:

```
py -3.12 -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
copy .env.example .env
```

Потом открой `.env` и впиши `MAX_BOT_TOKEN` (токен — лично у капитана).

На macOS/Linux вместо первых двух строк: `python3.12 -m venv .venv` и `source .venv/bin/activate`, вместо `copy` — `cp`.

## Каждый запуск

```
.venv\Scripts\activate
python -m uvicorn server.main:app --reload --port 3000
```

Остановить — `Ctrl+C`. В логе должно быть `Бот запущен: @t420_hakaton_max_bot`.

**Важно:** бота одновременно запускает только один человек. Если запустить у двоих, события будут случайно уходить то одному, то другому.

## Структура

```
server/
  main.py     веб-сервер + запуск бота
  bot.py      обработка сообщений и кнопок
  max_api.py  запросы к Bot API МАКС
  config.py   чтение .env
web/          мини-приложение (пока заглушка)
```

## Как работаем вдвоём

1. Перед началом: `git pull` — забрать чужие изменения.
2. После куска работы: `git add .`, `git commit -m "что сделал"`, `git push`.
3. `.env` в git не попадает — это нормально, токен у каждого свой файл.
